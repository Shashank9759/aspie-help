# aspie.help — website

One-page website for the aspie.help Autism & Asperger's WhatsApp community.
No build step: open `index.html`, or upload this folder to any static host.

| File | What it is |
|---|---|
| `index.html` | All page content |
| `styles.css` | Design, layout, animations |
| `script.js` | Calm mode, text size, animations, join pop-up, stories slider |
| `assets/favicon.svg` | Browser tab icon |

The WhatsApp setup guide and profile picture are in the separate folder `../aspie-help-whatsapp-kit/`, so they don't get published with the site.

## Before going live

1. **WhatsApp link:** in `script.js`, change `whatsappInvite` to your real invite link.
2. **Publish (free) on Netlify and connect aspie.help (GoDaddy):** follow `../aspie-help-whatsapp-kit/Hosting-Guide.md`.
3. **GoDaddy:** turn auto-renew OFF if you only want 1 year.

## Images

- **Famous people:** Wikimedia Commons photos under Creative Commons licences. Credits are listed on the page (*Photo credits*) — keep them.
- **Other photos:** Unsplash (free licence).
- Images load from Wikimedia/Unsplash, so the page needs internet to show them.

## Content notes

- Famous people are included only if they spoke publicly about their own diagnosis. The page says they don't endorse the site.
- The "Stories" quotes are examples (labelled on the page). Replace them with real member stories only with written permission.
- Check that the groups, rules and quiet hours on the page match your real WhatsApp community.

## Accessibility

Calm mode (turns off all movement), Larger text button, Atkinson Hyperlegible font, soft colours, no flashing, no puzzle-piece images, keyboard and screen-reader friendly.
